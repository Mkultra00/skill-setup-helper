# Three-minute demo

1. On Discover, show the live You.com results and a source briefing. These are real research leads; eligibility is unverified.
2. Click **Try guided demo**. This creates a fictional Example Audio case and a visibly labeled sample receipt. Preparation here is scripted so the presentation does not depend on a model call or real claimant facts.
3. Select **FICTIONAL-demo-receipt.txt**. Record: “The sample receipt shows a headset purchased on June 15, 2025.” Point out that uploading alone never clears the requirement.
4. The packet fingerprint changes. Confirm the individual practice statement and type **Jordan Example**. Click **Confirm & continue**.
5. Download the packet or click **Save draft to Gmail**, then **Review in Gmail**. This is a real One/Gmail draft containing a fictional case. No recipient is populated, nothing is sent and no submission portal exists for this case.
6. Show **Sandbox lab → Run in Daytona** for real isolated negative checks. Show **Agent memory** for user preferences. Real cases use the CrewAI preparation service; the guided fixture does not claim to invoke it.

Use a new guided demo for each presentation. Real case signatures remain the user's factual responsibility. This local preview is not a deployed multi-user service. No automated sending or claims submission is implemented.

Delete it manually in Daytona after the presentation when no longer needed. Audit logs show infrastructure actions; the individual test outcomes are in results.json and CLAIMANT.
